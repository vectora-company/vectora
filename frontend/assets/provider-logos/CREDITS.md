# Logos de providers

Logos oficiais usados para identificar cada provider na interface. Cada arquivo
vem da fonte oficial indicada e não foi redesenhado; apenas renomeado. As
variantes `-on-dark` têm o glifo claro (para fundos escuros) e as `-on-light`,
o glifo escuro (para fundos claros).
